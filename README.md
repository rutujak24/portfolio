## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required (static site)

### Running Locally

1. Open the project folder in your code editor
2. Open `index.html` in your web browser
3. Or use a local server:
   ```bash
   # Using Python 3
   python3 -m http.server 8000
   
   # Using Python 2
   python -m SimpleHTTPServer 8000
   
   # Using Node.js with http-server
   npx http-server
   ```
4. Visit `http://localhost:8000` in your browser

## 🛠️ Customization

### Changing Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-color: #f093fb;
    /* ... other variables ... */
}
```

### Adding New Sections
1. Add a new `<section>` in `index.html`
2. Create corresponding CSS styles in `styles.css`
3. Update navigation link in navbar

### Updating Content
- Edit content directly in `index.html`
- Update social links with your profiles
- Modify email and contact information
